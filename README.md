# 📒 Notes Manager

A simple and modern **full-stack Notes Management Web App** built using **Node.js, Express.js, EJS, MongoDB, HTML, CSS, and JavaScript**.

---

## ✨ Features

* 📝 Create new notes
* 📖 View all notes
* ✏️ Edit existing notes
* 🗑 Delete notes
* 🌙 Dark mode UI
* 💾 MongoDB database storage
* ⚡ Responsive design

---

## 🛠 Tech Stack

### Frontend

* HTML5
* CSS3
* JavaScript
* EJS

### Backend

* Node.js
* Express.js

### Database

* MongoDB Atlas
* Mongoose

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/notes-manager.git
cd notes-manager
```

### 2. Install dependencies

```bash
npm install
```

### 3. Create a `.env` file

```env
MONGO_URI=your_mongodb_connection_string
```

### 4. Start the server

```bash
npm start
```

Open in browser:

```
http://localhost:3000
```
